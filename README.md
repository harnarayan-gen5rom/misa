# Misa ♡

A romantic, responsive surprise website made just for Misa.

## What it includes
- Dreamy pastel gradients, glassmorphism, floating hearts
- A playful “Misa, do you love me?” question
- A mischievous “No” button that escapes mouse and touch
- A celebration, poem, and secret romantic reveal after “Yes”
- Fast, single-file HTML/CSS/JS; mobile-friendly and accessible to reduced-motion users

## Publish to GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then **Save**.
4. Visit the Pages link shown in Settings after GitHub deploys it.

## Rename the GitHub repository to misa
In **Settings → General → Repository name**, enter **misa** and click **Rename**. GitHub Pages project links use the repo name, so once published and renamed, the intended URL is `https://harnarayan-gen5rom.github.io/misa/` (subject to Pages settings).

The site itself is titled **For Misa ♡**.
